# ngrok-preview skill

A reusable Agent Skill for creating short-lived ngrok preview links for local artifacts and sharing them to users (especially for mobile/Telegram viewing workflows).

## Install (skills.sh ecosystem)

```bash
npx skills add https://github.com/wynnsu/skills-ngrok-preview --skill ngrok-preview
```

## Contents

- `skills/ngrok-preview/SKILL.md`
- `skills/ngrok-preview/scripts/ngrok_preview.py`
- `skills/ngrok-preview/references/troubleshooting.md`

## Notes

- Requires `ngrok` installed locally.
- Requires `ngrok` auth token configured.
